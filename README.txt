# Site — Trabalho Decente | ODS 8

## Arquivos
- `index.html`: estrutura e conteúdo do site.
- `style.css`: identidade visual, layout responsivo e acessibilidade visual.
- `script.js`: menu mobile, cards interativos, quiz e checklist.

## Como abrir no VS Code
1. Extraia o arquivo ZIP.
2. Abra a pasta `site_trabalho_decente` no VS Code.
3. Abra `index.html` no navegador. Recomendado: instalar a extensão **Live Server** no VS Code e clicar em **Go Live**.
4. Para publicar, envie os três arquivos para um serviço de hospedagem estática, como GitHub Pages, Netlify ou Vercel.

## Publicação
Este é um site estático. Não precisa de servidor, banco de dados ou instalação de dependências. Para publicar:
- GitHub Pages: crie um repositório, envie os três arquivos e habilite Pages nas configurações.
- Netlify/Vercel: importe o repositório ou arraste a pasta do site para o serviço, conforme as opções da plataforma.

## Privacidade
O quiz e o checklist funcionam no navegador. Nenhuma resposta é enviada para um servidor, e não há formulário de coleta de dados.

## Observações
- O site usa Google Fonts por conexão externa; se não houver internet, serão usadas fontes alternativas.
- Os links de ajuda levam a páginas oficiais. Confira os endereços antes de publicar.
- O conteúdo jurídico é educativo e resumido. Revise as informações com fontes oficiais ou orientação jurídica antes da publicação, pois a aplicação dos direitos depende do caso concreto e da legislação vigente.

## Novas dinâmicas sobre ambiente de trabalho
- Pilares interativos: seis cartões expansíveis sobre respeito, saúde, comunicação, inclusão, reconhecimento e participação.
- Termômetro do ambiente: reflexão com quatro perguntas e resultado educativo calculado localmente.
- Gerador de ideias: seleciona um desafio e apresenta sugestões de ações para discussão no RH.
- Situações do cotidiano: perguntas expansíveis com caminhos de prevenção e busca de apoio.

As respostas do termômetro não são armazenadas nem enviadas. O resultado não é diagnóstico, auditoria, avaliação psicológica ou conclusão jurídica.
